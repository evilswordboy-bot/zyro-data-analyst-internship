Ride Analytics & Revenue Intelligence Platform
Task 01: Build a Simple Ride Analytics Dashboard
Difficulty: Beginner    Estimated Time: 4–6 hours
Objective: Use a small ride dataset to clean the data, calculate a few simple numbers, and make an easy Power BI
dashboard.
1. Real-World Problem
 Ride companies have data about rides, fares, locations, and payments.
 Your job is to turn this raw data into a simple dashboard that answers basic business questions.
2. Week 2 Requirements
 Get a small ride-hailing dataset.
 Open and understand the data.
 Remove obvious duplicate or empty rows.
 Calculate a few basic KPIs.
 Create a simple Power BI dashboard.
 Show rides and revenue using easy charts.
 Write a short summary of what you learned.
3. Data Collection & Understanding
 Use a ride dataset with simple columns such as:
 Ride ID, Date, Pickup Location, Drop-off Location, Fare, Payment Method, Ride Status, Rating.
 For this beginner task, you do not need a large dataset. A small sample is enough to learn the process.
 Example row: R001 | 02-09-2026 | Lahore | DHA | 450 | Cash | Completed | 5
4. Data Cleaning
 Check for empty values.
 Remove duplicate ride IDs.
 Make sure Fare contains numbers.
 Make sure Date is in a correct date format.
 Remove clearly invalid rows, such as a negative fare.
 Keep the cleaning simple. Do not spend time on advanced data processing.
5. Basic KPI Analysis
 Calculate only these easy KPIs:
 Total Rides
 Completed Rides
 Cancelled Rides
 Total Revenue
 Average Fare
 Average Rating (if available)

6. Build a Simple Dashboard
 Use Power BI.
 Create 4–5 KPI cards at the top.
 Add simple charts:
  Rides by Date
  Revenue by Date
  Rides by Payment Method
  Rides by Status
  Top Pickup Locations
7. Simple Dashboard Example
 Total Rides: 100
 Completed Rides: 85
 Cancelled Rides: 15
 Total Revenue: PKR 42,000
 Average Fare: PKR 420
 The numbers above are only an example. Your dashboard should use the numbers from your dataset.
8. Simple Questions to Answer
 How many rides are there?
 How much revenue was made?
 Which payment method is used most?
 Which pickup location has the most rides?
 How many rides were cancelled?
 What is the average fare?
9. Recommended Beginner Tools
 Excel — to look at and clean the data.
 Power BI — to create the dashboard.
 Python/Pandas — optional if you already know Python.
 Git + GitHub — to submit your work.
10. Simple Project Structure
 ride-analytics/
 ■■■ data/
 ■■■ powerbi/
 ■■■ screenshots/
 ■■■ README.md
11. Basic Flow
 Dataset → Clean Data → Calculate KPIs → Power BI → Dashboard → Simple Insights
12. Required Deliverables
 Cleaned dataset.
 Power BI dashboard.
